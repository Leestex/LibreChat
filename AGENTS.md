# What matters when this app is tested

## Critical user flows (P0)
1. Sending a chat message: a signed-in user types a message in the chat input, sends it, and the reply appears in the conversation.
2. Sharing a conversation: a user creates a share link for a conversation from its menu, or exports it.

## Accounts and roles
- An administrator account manages agents and the admin settings; a regular user cannot.

## Matters least
- The theme picker: cosmetic only.
